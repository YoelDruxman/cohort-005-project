# A Purchase gets one Refund Request, and the ruling is final

Each Purchase can have at most one Refund Request. Once an Admin approves or declines it, the learner can't submit another. A second request would just reargue the same facts with no new information, and allowing it would let learners keep reopening decided cases and flood the Admin queue. A learner who really disagrees can contact support, but the product itself doesn't offer an appeal.

This is a deliberate departure from the earlier model, where a declined learner could submit again. Don't reintroduce that without revisiting this decision.
